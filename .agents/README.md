# 프로젝트 Antigravity 커스터마이징 (Project Antigravity Customizations)

이 디렉터리는 팀 전체에서 공유되는 Google Antigravity 에이전트의 워크스페이스 레벨 커스터마이징(Workspace-level Customizations) 설정을 포함합니다.

## 디렉터리 구조 (Directory Structure)
- **rules/**: 코딩 표준(Coding standards), 아키텍처 제약 조건 및 보안 가이드라인(Security guidelines).
- **skills/**: 특화된 다단계 워크플로우(Workflows), 런북(Runbooks) 및 작업 자동화 스킬.
- **agents.md**: 커스텀 서브에이전트 페르소나(Custom subagent personas) 및 도구 권한 매핑.
- **hooks.json**: 수명 주기 자동화 훅(Lifecycle automation hooks - linter, formatting, verification).
- **mcp_config.json**: Model Context Protocol (MCP) 서버 연동 설정.
